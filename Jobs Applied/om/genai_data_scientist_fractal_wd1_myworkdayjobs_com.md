Job Description Job Title: Data Scientist with GenAI Experience Job Summary: We are seeking an experienced Data Scientist with a focus on Gen AI and a minimum of 5 years of industry experience. The ideal candidate will have a strong background in machine learning, statistical analysis, and data modeling, with a specific emphasis on extracting insights from textual data. This role involves working on complex NLP projects to derive meaningful patterns and knowledge from large datasets. Key Responsibilities: 1. **NLP Model Development:** - Develop and implement NLP models for various applications, including text classification, sentiment analysis, entity recognition, and language translation. - Utilize machine learning and deep learning techniques to extract valuable information from unstructured text. 2. **Text Preprocessing:** - Preprocess and clean large volumes of text data to prepare it for analysis. - Implement techniques such as tokenization, stemming, and lemmatization. 3. **Feature Engineering:** - Identify and engineer relevant features from text data to improve model performance. - Implement techniques to capture semantic relationships within the data. 4. **Model Training and Evaluation:** - Train, fine-tune, and validate NLP models using appropriate algorithms. - Evaluate model performance using metrics such as precision, recall, F1 score, and accuracy. 5. **Data Analysis:** - Conduct exploratory data analysis on textual datasets to uncover patterns, trends, and anomalies. - Use statistical methods to gain insights into the underlying structure of the data. 6. **Collaboration with Cross-Functional Teams:** - Work closely with data engineers, software developers, and domain experts to integrate NLP solutions into broader systems and applications. - Collaborate in defining project goals, requirements, and deliverables. 7. **Algorithm Optimization:** - Optimize and fine-tune NLP algorithms for improved efficiency and accuracy. - Implement parallel processing and distributed computing techniques for large-scale data analysis. 8. **Stay Updated with NLP Trends:** - Stay informed about the latest advancements and trends in NLP and machine learning. - Apply cutting-edge techniques to solve complex business problems. 9. **Documentation:** - Document methodologies, algorithms, and code for reproducibility and knowledge transfer. - Prepare clear and concise project reports and documentation. Qualifications: - Master's in Computer Science, Data Science, Statistics, or a related field. - Minimum of 3 years of professional experience in data science, with a focus on GenAi. - Strong programming skills in languages such as Python or R. - Expertise in using NLP libraries and frameworks such as NLTK, SpaCy, or TensorFlow. - Proficiency in machine learning techniques, including supervised and unsupervised learning. - Experience with deep learning frameworks like TensorFlow or PyTorch. - Strong understanding of text mining, information retrieval, and semantic analysis. - Excellent problem-solving and analytical skills. - Effective communication and collaboration skills. - Experience with cloud platforms (e.g., AWS, Azure) and big data technologies is a plus. If you are a skilled Data Scientist with a specialization in NLP, passionate about deriving insights from textual data, and have a proven track record, we encourage you to apply.
